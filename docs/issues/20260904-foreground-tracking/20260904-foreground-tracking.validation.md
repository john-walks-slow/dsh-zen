# 20260904-foreground-tracking 用户验证

## 验证说明

- 验证对象：盯屏时间统计的判定语义修复
  - ① 窗口可见（即使未聚焦）即算盯屏；
  - ② agent 在问问题/请求权限、等待用户选择/批准期间不计入运行时长。
- 环境/前置条件：DSH Web 页面已刷新（插件已重新构建部署到 `~/.dsh/profiles/web`）；浏览器需保持页面可见。
