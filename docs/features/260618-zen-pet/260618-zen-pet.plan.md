# Zen Pet — 桌宠功能计划

## 目标

在 Zen 视图中，用一只状态感知的桌宠替代当前的 header 区域（🐋 + 消息文本），让用户一眼看出 agent 在干什么，不用盯屏。

## 设计

### 状态映射

从 `chatSnapshot` 的 `node.kind` + `node.data` 推断 agent 当前状态：

| 桌宠状态 | 检测条件 | 动画描述 |
|---------|---------|---------|
| `idle` | `blank` 为 true（无会话内容） | 🐱 安静呼吸，偶尔眨眼 |
| `thinking` | `running` && 最后一个节点是 `assistant-step` 且其 `blocks` 末尾有 `kind: "reasoning"` | 🤔 挠头，`?` `💡` 漂浮 |
| `tooling` | `running` && 最后一个节点是 `tool-call` | 🔧 敲键盘，工具图标漂浮 |
| `commanding` | `running` && 最后一个节点是 `command` | 💻 原地跑，出汗 |
| `compacting` | `running` && 最后一个节点是 `compaction` | 🧹 扫地 |
| `error` | 最后一个节点是 `turn-error` 或 `model-retry` 或 `turn-max-tokens` | 😵 颤抖，`!` 漂浮 |
| `done` | `!running` && 有 AI 回复 | 🎉 跳跃，星星闪烁 |
| `idle-running` | `running` 但无法确定具体子状态 | 🐋 平稳游动（兜底） |

### 动画实现

采用 **emoji + CSS keyframe** 方案：

- 桌宠本体：一个大号 emoji（48px），根据状态切换
- 动画效果：CSS keyframe 动画（bounce / shake / float / breathe）
- 漂浮粒子：在桌宠上方生成小符号（`?` `💡` `</>` `!` `✨` 等），CSS 上浮 + 淡出
- 每个状态有独立的动画 class

选择 emoji 而非 SVG 的理由：
1. 零资源依赖，不需要任何图片文件
2. 跨平台一致性好
3. 用户可直观理解
4. 实现简单，几行 CSS 即可

### 组件结构

```
ZenPet (新组件)
├── 桌宠本体 (emoji + CSS animation)
├── 漂浮粒子层 (绝对定位的小符号)
└── 状态文案 (保留原来的 message + sub)
```

替换关系：
- 原来 `.dsh-zen-center` 里的 `icon` + `message` + `sub` → 由 `ZenPet` 组件接管
- ZenView 不再直接渲染 icon/message/sub，改为渲染 `<ZenPet state={...} t={t} />`
- done 状态下不显示桌宠（保持原有的"只有 AI 回复"的干净设计），或者显示一个低调的庆祝动画

### 状态检测函数

新增 `detectPetState(chatSnapshot, running, blank)` 函数：

```
function detectPetState(running, blank, chatSnapshot):
  if blank → "idle"
  if !running → "done" (有回复) / "idle" (无回复)

  // running = true，检查最后一个节点
  lastNode = chatSnapshot.nodes.get(order.last)
  switch lastNode.kind:
    "assistant-step" → 检查 blocks 末尾：
      有 kind:"reasoning" → "thinking"
      有 kind:"text" → "idle-running" (正在输出文本)
      否则 → "idle-running"
    "tool-call" → "tooling"
    "command" → "commanding"
    "compaction" → "compacting"
    "turn-error" / "model-retry" / "turn-max-tokens" → "error"
    default → "idle-running"
```

### ZenView 改动

1. 新增 `ZenPet.tsx` 组件
2. ZenView 中 import ZenPet
3. 用 `<ZenPet>` 替换原来的 running 状态渲染块和空状态渲染块
4. done 状态保持不变（AI reply bubble）
5. Zen settings 新增 `showPet` 开关（默认 on）

### 每个状态的渲染

```tsx
const STATE_CONFIG = {
  idle:         { emoji: "🐱", animation: "breathe", particles: [] },
  thinking:     { emoji: "🤔", animation: "think",    particles: ["❓", "💡"] },
  tooling:      { emoji: "🔧", animation: "work",    particles: ["</>", "{}"] },
  commanding:   { emoji: "💻", animation: "work",    particles: ["⌨️", "📊"] },
  compacting:   { emoji: "🧹", animation: "sweep",   particles: ["📦", "✨"] },
  error:        { emoji: "😵", animation: "shake",   particles: ["❗", "💥"] },
  done:         { emoji: "🎉", animation: "celebrate", particles: ["⭐", "✨"] },
  "idle-running": { emoji: "🐋", animation: "swim",  particles: ["~", "~"] },
};
```

### 粒子系统

- 每隔 1.5-2s 生成一个粒子（从 `particles` 数组中随机选）
- 粒子从桌宠上方随机位置出现，向上漂浮 30px，淡出
- 使用 React state + setInterval 管理粒子列表
- 最多同时 3 个粒子

### done 状态的特殊处理

done 状态下桌宠显示一个短暂的庆祝动画（约 2s），然后淡出。或者持续显示但动画更柔和。

考虑到用户偏好"done 状态干净"，方案是：done 状态下桌宠显示在 AI 回复上方，做低调的呼吸 + 偶尔闪烁星星，不做大幅度庆祝。
